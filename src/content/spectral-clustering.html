These notes develop k -means and spectral clustering from an optimization viewpoint. After proving the descent and finite termination of Lloyd's algorithm, we formulate a balanced graph-partitioning problem, derive its spectral relaxation, and show how the resulting Fiedler vector is related to the eigenmodes of a random walk on a similarity graph.

These notes grew out of Prof. Alexis Drouot's MATH 480 course at the University of Washington, Seattle (Winter 2025). I have reorganized and expanded my course notes and have done my best to ensure correctness, but errors may remain.

1K-means clustering

Let x 1 , … , x N ∈ R d be the data and let 1 ≤ k ≤ N be the desired number of clusters. K-means seeks centers C = ( C 1 , … , C k ) ∈ ( R d ) k around which the data cluster.

1.1Lloyd's algorithm

Fix a deterministic rule for breaking ties between equally close centers. Choose initial centers C 0 = ( C 1 0 , … , C k 0 ) , often as k distinct points sampled from x 1 , … , x N .

For m = 0 , 1 , 2 , … , repeat the following steps.

  1. Given C m , assign every data point to a nearest center. If a m ( j ) ∈ { 1 , … , k } is the assigned label of x j , then
    a m ( j ) ∈ arg min 1 ≤ ℓ ≤ k ‖ x j − C ℓ m ‖ .
    Define the corresponding sets of indices by I ℓ m = { j ∈ { 1 , … , N } : a m ( j ) = ℓ } . Thus { 1 , … , N } = ⨆ ℓ = 1 k I ℓ m .
  2. Assuming each I ℓ m is nonempty, replace each center by the mean of its assigned observations:
    C ℓ m + 1 = 1 | I ℓ m | ∑ j ∈ I ℓ m x j , ℓ = 1 , … , k .
  3. Stop if C m + 1 = C m ; otherwise continue.

The displayed update requires every I ℓ m to be nonempty. In an implementation, empty clusters need an explicit rule, such as retaining the old center or reinitializing it in a way that does not increase the objective. For the theoretical discussion below, we assume that all clusters remain nonempty.

1.2Objective and descent

Define the k -means objective

E ( C ) = ∑ j = 1 N min 1 ≤ ℓ ≤ k ‖ x j − C ℓ ‖ 2 .

It is often convenient to introduce an assignment a : { 1 , … , N } → { 1 , … , k } and the joint objective

Q ( C , a ) = ∑ j = 1 N ‖ x j − C a ( j ) ‖ 2 .

For fixed C , a nearest-center assignment minimizes Q ( C , a ) over a ; for fixed a , the cluster means minimize Q ( C , a ) over C .

Lemma 1.1 (The sample mean minimizes squared distance). Let z 1 , … , z n ∈ R d and z ¯ = n − 1 ∑ j = 1 n z j . Then z ¯ is the unique solution of

min c ∈ R d ∑ j = 1 n ‖ z j − c ‖ 2 .

Proof. Let f ( c ) = ∑ j = 1 n ‖ z j − c ‖ 2 . Expanding gives

f ( c ) = n ‖ c ‖ 2 − 2 c ⊤ ∑ j = 1 n z j + ∑ j = 1 n ‖ z j ‖ 2 = n ‖ c − z ¯ ‖ 2 + ∑ j = 1 n ‖ z j ‖ 2 − n ‖ z ¯ ‖ 2 .
The final two terms do not depend on c , and the first is nonnegative with equality exactly when c = z ¯ . ◻

Theorem 1.2 (Monotonicity and finite termination). Assume that ties are broken deterministically and all clusters remain nonempty. The iterates of Lloyd's algorithm satisfy

E ( C 0 ) ≥ E ( C 1 ) ≥ E ( C 2 ) ≥ ⋯ .
Moreover, equality E ( C m + 1 ) = E ( C m ) forces C m + 1 = C m . Consequently the algorithm reaches a fixed point after finitely many iterations.

Proof. Let a m denote the nearest-center assignment associated with C m . The sample-mean lemma, applied separately to every nonempty cluster, gives

E ( C m ) = Q ( C m , a m ) ≥ Q ( C m + 1 , a m ) .
Reassigning each point to a nearest new center can only improve the joint objective, so
Q ( C m + 1 , a m ) ≥ Q ( C m + 1 , a m + 1 ) = E ( C m + 1 ) .
This proves monotonicity. If E ( C m + 1 ) = E ( C m ) , then equality holds in the first inequality above. By uniqueness of the sample mean, every old center already equals the mean of its assigned cluster, and hence C m + 1 = C m .

There are only finitely many assignments, at most k N , and each assignment with nonempty clusters determines a unique tuple of cluster means. After the first update, every center tuple produced by the algorithm is therefore one of finitely many such tuples. Between two distinct center tuples the objective decreases strictly. Hence no nonfixed center tuple can repeat, and the algorithm must reach a fixed point after finitely many iterations. ◻

Remark 1.3. The fixed point need not be a global minimizer of E . K-means is sensitive to initialization, so multiple restarts or k -means++ initialization are often used in practice.

2Spectral clustering

K-means can perform poorly when clusters are nonconvex, as in the familiar “two moons” example. Spectral clustering instead encodes the data as a weighted graph: nearby, similar points receive a large edge weight and should preferably receive the same label.

2.1A balanced two-cluster problem

Suppose N is even and we seek two clusters of equal size. Assign labels

z i ∈ { − 1 , 1 } , Ω + = { x i : z i = 1 } , Ω − = { x i : z i = − 1 } .

The balance condition is ∑ i = 1 N z i = 0 .

With an ε -neighborhood graph, a natural disagreement energy is

E ( z ) = ∑ i , j = 1 N 1 { ‖ x i − x j ‖ ≤ ε } | z i − z j | 2 .

It penalizes nearby points given opposite labels. Because the sum runs over ordered pairs ( i , j ) , every undirected edge is counted twice.

More generally, choose a nonnegative, nonincreasing similarity function w : [ 0 , ∞ ) → [ 0 , ∞ ) , so that close points receive large weights. The indicator above corresponds to

w ( r ) = { 1 , r ≤ ε , 0 , r > ε .

Relax z i ∈ { − 1 , 1 } to z i ∈ R . The constraint ∑ i z i 2 = N retains the scale of the discrete labels and excludes the trivial vector z = 0 . The relaxed problem is

min z ∈ R N   ∑ i , j = 1 N w ( ‖ x i − x j ‖ ) | z i − z j | 2 , subject to    ∑ i = 1 N z i = 0 , ∑ i = 1 N z i 2 = N .
(M)

The relaxed vector embeds the data points on the real line. A two-way partition can be obtained by thresholding at zero. If an exactly balanced partition is required, assign the N / 2 smallest coordinates to one cluster and the N / 2 largest to the other.

2.2Graph Laplacian form

Define the symmetric weight matrix and degree matrix by

W i j = w ( ‖ x i − x j ‖ ) , D = diag ( d 1 , … , d N ) , d i = ∑ j = 1 N W i j .

The unnormalized graph Laplacian is L = D − W .

Lemma 2.1 (Dirichlet energy). For every z ∈ R N ,

∑ i , j = 1 N W i j | z i − z j | 2 = 2 z ⊤ ( D − W ) z = z ⊤ M z , M := 2 D − 2 W = 2 L .

Proof. Using W i j = W j i ,

∑ i , j = 1 N W i j ( z i − z j ) 2 = ∑ i , j W i j z i 2 + ∑ i , j W i j z j 2 − 2 ∑ i , j W i j z i z j = 2 z ⊤ D z − 2 z ⊤ W z = 2 z ⊤ ( D − W ) z .   ◻

In particular, M is positive semidefinite because its quadratic form is a sum of nonnegative terms. Also M 1 = 0 , since D 1 = W 1 .

2.3The Courant–Fischer theorem

For a real symmetric matrix A ∈ R n × n and x ≠ 0 , define the Rayleigh quotient

R A ( x ) = x ⊤ A x x ⊤ x .

Theorem 2.2 (Courant–Fischer). Let the eigenvalues of A be ordered as λ 1 ≥ ⋯ ≥ λ n . For k = 1 , … , n ,

λ k = max S ≤ R n dim S = k   min x ∈ S x ≠ 0 R A ( x ) , λ k = min T ≤ R n dim T = n − k + 1   max x ∈ T x ≠ 0 R A ( x ) .

Proof. Because A is symmetric, it has an orthonormal eigenbasis v 1 , … , v n , with A v i = λ i v i . If x = ∑ i = 1 n c i v i , then

R A ( x ) = ∑ i = 1 n λ i c i 2 ∑ i = 1 n c i 2 ,
a weighted average of the eigenvalues.

Take S 0 = span { v 1 , … , v k } . Every nonzero x ∈ S 0 satisfies R A ( x ) ≥ λ k , and equality is attained at v k . Hence the max–min is at least λ k .

Conversely, let S be any k -dimensional subspace and set V = span { v k , … , v n } , whose dimension is n − k + 1 . The dimension formula gives

dim ( S ∩ V ) ≥ k + ( n − k + 1 ) − n = 1.
For a nonzero x ∈ S ∩ V , R A ( x ) ≤ λ k . Thus
min x ∈ S ∖ { 0 } R A ( x ) ≤ λ k
for every S , proving the max–min formula. The min–max formula follows by the same argument with the roles of the top and bottom eigenspaces reversed. ◻

2.4Solution of the spectral relaxation

Theorem 2.3 (Fiedler-vector solution). Let the eigenvalues of M = 2 ( D − W ) be

0 = μ 1 ≤ μ 2 ≤ ⋯ ≤ μ N ,
counted with multiplicity. If the weighted graph is connected, then μ 1 = 0 is simple and an associated unit eigenvector is
v 1 = 1 N .
Every solution of (M) has the form
z ∗ = N v ,
where v is a unit eigenvector in the eigenspace of the second-smallest eigenvalue μ 2 . The minimum value is N μ 2 .

Proof. Choose an orthonormal eigenbasis v 1 , … , v N of M with v 1 = 1 / N . The balance constraint z ⊤ 1 = 0 implies

z = ∑ r = 2 N α r v r ,
and the norm constraint gives
∑ r = 2 N α r 2 = N .
Therefore
z ⊤ M z = ∑ r = 2 N μ r α r 2   ≥   μ 2 ∑ r = 2 N α r 2 = N μ 2 .
Equality holds exactly when z lies in the μ 2 -eigenspace and has norm N . ◻

Remark 2.4. If the graph has c > 1 connected components, then the nullspace of M has dimension c . A nonconstant vector in that nullspace can be orthogonal to 1 , so the relaxed minimum is zero and components can be separated without cutting a positive-weight edge. The connectedness assumption is what makes the first nonconstant mode the usual Fiedler vector.

3Probabilistic interpretation

For a general weighted graph with degree matrix D , the associated random walk has transition matrix P = D − 1 W , provided every degree is positive. This matrix is row-stochastic, although it need not be symmetric even when W is symmetric.

To make the spectral relation especially transparent, we now consider the special case of a symmetric, nonnegative, row-stochastic transition matrix P , so ∑ j = 1 N P i j = 1 for every i . It may be viewed as the transition matrix of a random walk on the data graph, with P i j = Pr ( Y t + 1 = j ∣ Y t = i ) .

For the column probability vector

F ( t ) = ( Pr ( Y t = 1 ) ,   … ,   Pr ( Y t = N ) ) ⊤ ,

the usual row-transition convention gives

F ( t + 1 ) = P ⊤ F ( t ) = P F ( t ) , F ( t ) = P t F ( 0 ) ,

where the second equality uses symmetry. Symmetry and stochasticity imply that the uniform distribution 1 N 1 is stationary.

Lemma 3.1 (Spectrum of a symmetric stochastic matrix). Assume the graph of P is connected. Order the eigenvalues as

1 = η 1 > η 2 ≥ ⋯ ≥ η N ≥ − 1.
Then
u 1 = 1 N
is a unit eigenvector for η 1 = 1 , and the eigenvalue 1 is simple.

Proof. Since P 1 = 1 , the number 1 is an eigenvalue. For any x ∈ R N , symmetry, nonnegativity, and 2 | x i x j | ≤ x i 2 + x j 2 yield

| x ⊤ P x | ≤ ∑ i , j P i j | x i x j | ≤ 1 2 ∑ i , j P i j ( x i 2 + x j 2 ) = x ⊤ x .
Thus every eigenvalue lies in [ − 1 , 1 ] .

If P v = v , choose an index r for which v r = max i v i (replacing v by − v if needed). Then

v r = ∑ j P r j v j ≤ ∑ j P r j v r = v r .
Equality forces every neighbor of r with positive transition probability to have the same value v r . Connectivity propagates this equality to all vertices, so v is proportional to 1 . Hence the eigenspace for 1 is one-dimensional. A real symmetric matrix is orthogonally diagonalizable, so algebraic and geometric multiplicities agree and η 2 < 1 . ◻

Let u 1 , … , u N be an orthonormal eigenbasis of P . The spectral decomposition gives

P t = ∑ j = 1 N η j t u j u j ⊤ .

Consider the Laplacian-form matrix M P = 2 I − 2 P . The matrices M P and P have the same eigenvectors, and an eigenvalue η of P corresponds to the eigenvalue 2 ( 1 − η ) of M P . The second-smallest eigenvector of M P is therefore a second-largest eigenvector of P .

If z is normalized so that ‖ z ‖ = N , take

u 1 = 1 N , u 2 = z N .

Then

P t = 1 N 1 1 ⊤ + 1 N η 2 t z z ⊤ + ∑ j = 3 N η j t u j u j ⊤ .

Thus the spectral-clustering coordinate is the nonconstant eigenmode associated with the second-largest eigenvalue of the transition matrix. When the nontrivial spectrum is nonnegative, this is also the slowest-decaying nonconstant mode.

Remark 3.2 (Periodicity). Connectedness alone does not ensure that P t converges: for example, a random walk on a bipartite graph can have eigenvalue − 1 . If the chain is also aperiodic, then

| η j | < 1 for all  j ≥ 2 ,
and
P t ⟶ 1 N 1 1 ⊤ .
A common fix is the lazy walk P ~ = I + P 2 . It preserves the eigenvectors and transforms each eigenvalue η j into ( 1 + η j ) / 2 ∈ [ 0 , 1 ] . In particular, for the lazy walk the second-largest eigenvalue corresponds to the slowest-decaying nonconstant mode.
